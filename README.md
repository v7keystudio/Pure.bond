>
> 💖 Pure.bond — Raksha Bandhan Interactive Experience

«A beautiful, interactive web experience created to celebrate the purest bond between a brother and sister. 🎀»

Pure.bond is a modern, animated Raksha Bandhan-themed website featuring interactive pages, gift ideas, cherished memories, smooth transitions, background music, and a heartfelt special wish.

---

✨ Features

- 🎀 Interactive Raksha Bandhan Welcome Page
- 🎁 Gift Suggestions for Sister
- 🖼️ Cherished Memories Gallery
- 🔍 Full-Screen Image Preview Modal
- 💌 Special Raksha Bandhan Wish Modal
- 🎵 Background Music with Music Toggle
- ✨ Floating Particle Animation
- 🎬 Smooth GSAP Page Transitions
- 💫 Animated Cards & Hover Effects
- 📱 Responsive Design for Mobile & Desktop
- 🏠 Easy Navigation Between Pages

---

🛠️ Tech Stack

Technology| Purpose
HTML5| Website structure
Tailwind CSS| Responsive UI & styling
JavaScript| Interactions & functionality
GSAP| Page & element animations
Google Fonts| Typography
HTML5 Audio| Background music

The project uses Tailwind CSS, GSAP, Google Fonts, and custom JavaScript to create the interactive experience.

🎨 Experience Flow

01 — Welcome

The experience starts with a dedicated Raksha Bandhan welcome screen featuring:

- Animated heading
- Heartfelt message
- Floating particles
- Smooth entrance animation
- Let's Celebrate button

02 — Gifts For Sister

Users can explore a collection of gift ideas including:

- 🍫 Gourmet Chocolates
- 💎 Elegant Bracelet
- 👗 Stylish Dress
- 🌸 Exotic Perfume

Each card includes animated styling and hover effects.

03 — Cherished Memories

The final page contains a responsive memory gallery where users can:

- Browse Raksha Bandhan memories
- Click images to view them in a larger modal
- Open a special personal wish
- Return to the home page

---

🎵 Music Experience

The website includes background music with an interactive music control.

The music:

- Loads from "songu.mp3"
- Runs in a loop
- Starts when browser interaction allows it
- Can be paused/resumed using the floating music button
- Uses a controlled volume level for a softer experience

---

✨ Animations

The project uses GSAP for smooth transitions and interactive animations.

Animations include:

- Page-to-page sliding transitions
- Fade-in effects
- Staggered element animations
- Modal animations
- Image scaling
- Floating gift cards
- Particle movement

🚀 Run Locally

No framework or build system is required.

1. Clone the repository

git clone https://github.com/v7keystudio/Pure.bond.git

2. Open the project

Navigate into the project folder:

cd Pure.bond

3. Run the website

Simply open:

Raksh.html

in your browser.

For the best experience, you can also use VS Code + Live Server.
